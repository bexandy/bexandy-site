Sitio estático con dos puertas, trabajo y baile. Las utilidades y el reproductor de salsa son componentes React que corren solo en el navegador.

## Decisiones
- Astro para el contenido, React solo donde hay interacción.
- Cloudflare Workers con static assets: requests estáticos gratis e ilimitados.
- R2 para modelos de IA y audio demo, con egreso gratuito.
